# Bundled web fonts

Subsets (Latin, Greek, punctuation, arrows, mathematical operators) converted to
WOFF with fontTools 4.65 from the Debian `fonts-inter` and `fonts-stix` packages.
Both are licensed under the SIL Open Font License 1.1 ([OFL.txt](OFL.txt)).

| school-serif-{400,400i,600}.woff | STIX Two Text Regular/Italic/SemiBold | 2001–2021 The STIX Fonts Project Authors; STI Pub Companies; MicroPress, Inc.; Elsevier, Inc. |

The STIX-derived subsets are Modified Versions under the OFL and are therefore
renamed “School Serif”; they do not use the STIX Reserved Font Names.
STIX Fonts™ is a trademark of the IEEE. Fonts are self-hosted so that no
learner request is sent to a third-party font service.
