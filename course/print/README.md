# Print set for the two primers

Print-ready PDFs built from the Markdown sheets by `build_print.py`
(XeLaTeX, DejaVu fonts). Rebuild after changing a worksheet or answer sheet:
`.venv/bin/python course/print/build_print.py`. Check one real printout for
formulas, tables and small units before teaching; the answer sheets are kept
back and handed out in stages. Overview: [instructor overview](../instructor_overview.md).
