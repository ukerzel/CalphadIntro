# Lesson 8 — the same binary model in a database and a tool

Meetings 19–20. Prerequisites: Lessons 4–7, the unary load/evaluate/minimize

Exit goal: map each TDB term to the known equation, distinguish fixed homogeneous
properties from equilibrium, and verify phase amounts/compositions rather than
trusting a phase name or solver status. This is the same invented binary, not a

## 8.1 Read the representation before solving anything

The original [binary_family.tdb](binary_family.tdb) contains one substitutional
sublattice per phase. Its site ratio is one. A and B occupy the same kind of site;
here site fraction of B equals mole fraction of B atoms. That equality is specific
to this simple model, not a universal rule for ionic or multiple-sublattice models.
ALPHA and BETA remain invented phase labels, not identified crystal structures.

The core entries are:

```text
FUNCTION LZERO 600 0; 1800 N !
PHASE ALPHA % 1 1 !
CONSTITUENT ALPHA :A,B: !
PARAMETER G(ALPHA,A;0) 600 1000-10*T; 1800 N !
PARAMETER G(ALPHA,B;0) 600 13000-10*T; 1800 N !
PARAMETER L(ALPHA,A,B;0) 600 LZERO; 1800 N !
PHASE BETA % 1 1 !
CONSTITUENT BETA :A,B: !
PARAMETER G(BETA,A;0) 600 13000-10*T; 1800 N !
PARAMETER G(BETA,B;0) 600 1000-10*T; 1800 N !
```

The full file also declares components and the `%` phase-type syntax. Elemental
masses/reference metadata are explicitly placeholders, not Lesson 3's invented
mass-conversion data or physical elemental assessments. TDB terminators and
syntax come from the tool's database format [1]; the expressions are ours.

| Known term | Database/tool representation | What to check |
|---|---|---|
| ALPHA pure-A / pure-B G | two ALPHA `PARAMETER G` entries | 1000−10T / 13000−10T |
| BETA pure-A / pure-B G | two BETA `PARAMETER G` entries | references exchanged |
| weighted endmember reference | one sublattice with A/B site fractions | A weight 1−x, B weight x |
| ideal RTq entropy term | generated by the substitutional phase model | do not add RTq again in a G parameter |
| ALPHA Ωx(1−x) | zeroth-order `L(ALPHA,A,B;0)` | override `LZERO` with declared Ω |
| I2 phase set | explicit ALPHA and BETA, Ω=0 | both branches compete |
| R1 phase set | explicit ALPHA only, Ω=20000 | two ALPHA regions may coexist |

`LZERO` defaults to zero in the file. The API's `parameters={'LZERO': value}`
overrides that function when building/evaluating the model [2]. Every call records
its intended variant; do not rely on a previous cell's hidden parameter setting.
For fitting later, only homogeneous ALPHA will use trial Ω in [0,24000] J/mol.
The wrapper enforces T=600–1800 K itself: a TDB interval is not a substitute for
checking whether a tool extrapolates expressions outside an intended domain.

## 8.2 Evaluate a supplied composition before allowing it to separate

`calculate` evaluates a homogeneous phase model. If points are omitted, the tool
samples internal site fractions automatically; that output is not necessarily at
the composition requested by a hand table. In this one-sublattice model, use
explicit `[1−x,x]` points in sorted A,B order and inspect returned `X` [2].
The wrapper returns `actual_x` with G/H/S and rejects an unexpected composition
shift or nonfinite output. It does not call equilibrium to obtain these properties.

At 1000 K the checked homogeneous values are:

| Phase / Ω, J/mol | actual x | G, J/mol | H, J/mol | S, J/(mol K) |
|---|---:|---:|---:|---:|
| ALPHA / 0 | 0.2 | −10760.595951 | 3400 | 14.160596 |
| ALPHA / 0 | 0.5 | −8763.172233 | 7000 | 15.763172 |
| BETA / 0 | 0.2 | −3560.595951 | 10600 | 14.160596 |
| BETA / 0 | 0.8 | −10760.595951 | 3400 | 14.160596 |
| ALPHA / 20000 | 0.2 | −7560.595951 | 6600 | 14.160596 |
| ALPHA / 20000 | 0.5 | −3763.172233 | 12000 | 15.763172 |

Compare with the plain formula at **actual x**, and check exact pure limits
separately. At x=0/1 our explicit property calls returned exact compositions;
this is retained evidence for this model/API, not permission to assume all tools
or models keep endpoints exact. An offset must be reported, not silently relabelled.

Notice R1 at x=0.5: homogeneous mixing H=12000−7000=5000 J/mol. The state may be
unstable, but its homogeneous model property is still a well-defined evaluation.
That distinction matters when matching a specified observation to a forward model.

## 8.3 Equilibrium may return multiple regions with the same phase name

`equilibrium` minimizes at fixed T,p,total amount and overall composition [2].
The wrapper sets N=1 mol, P=100000 Pa, X(B)=z, explicit phases and Ω. It records
sampling density 2000; increasing it is not a replacement for numerical comparison
or a proof of a global optimum. Plain analytical R1/I2 controls remain independent.

At 1000 K, z=0.5, the actual tool result rounded for teaching is:

| Variant | Region phase | Region B composition | Region amount fraction | Equilibrium g, J/mol |
|---|---|---:|---:|---:|
| I2 | ALPHA | 0.191040753 | 0.5 | −10762.730017 |
| I2 | BETA | 0.808959247 | 0.5 | −10762.730017 |
| R1 | ALPHA | 0.169144007 | 0.5 | −3968.472910 |
| R1 | ALPHA | 0.830855993 | 0.5 | −3968.472910 |

The equilibrium energy is per mole of the **whole sample** and is repeated in
each row only for readability. Do not sum it once per row. Multiply each region's
own energy by its amount fraction when reconstructing G. Do not store R1 regions
in a dictionary keyed only by phase name: that would overwrite one composition.
An array slot with an empty phase label is not an extra phase. A zero-amount
phase has no uniquely determined active composition. The wrapper retains only
positive-amount physical regions and checks both component balances.

**Pause:** does `phases=['ALPHA']` force a homogeneous R1 state? No. Two ALPHA
composition regions can minimize G. Use fixed-composition property evaluation
when the requested observable is homogeneous.

## 8.4 Detect three ways to calculate a different problem

1. Forget Ω=20000 for R1: at x=0.5 the homogeneous G is lower by 5000 J/mol because
   the interaction term was omitted. A successful parser does not detect that.
2. Omit BETA from I2: the equimolar result becomes homogeneous ALPHA at −8763.172233
   J/mol rather than −10762.730017. The amount balance may still pass; phase scope
   and an independent energy check detect the changed question.
3. Replace a homogeneous enthalpy by the enthalpy of the G-equilibrium split:
   at R1,1000 K, z=0.5, equilibrium mixing H is about 2810.686236 J/mol after the
   same overall pure-reference subtraction. It is not the requested homogeneous
   5000 J/mol. Equilibrium selects minimum **G**, not minimum H. This discrepancy
   must be rejected, not fitted away or fixed by changing temperature.

Reference typos also matter: replacing a13000 endmember coefficient by 12000 shifts
its x=0.5 weighted reference by −500 J/mol. Pointwise phase evaluation should fail
before relying on an equilibrium comparison. Record source, domain, phases,
parameters and actual compositions, then compute errors at unchanged tolerances.

## 8.5 Optional exact cell

From the repository root in the pinned Poetry environment:

```python
from course.foundations.binary_family_tools import homogeneous_properties, binary_equilibrium

p = homogeneous_properties(1000.0, 0.5, 'ALPHA', 20000.0)
print(f"homogeneous {float(p['actual_x']):.6f} {float(p['GM']):.6f} {float(p['HM']):.6f}")
for variant in ('I2', 'R1'):
    state = binary_equilibrium(1000.0, 0.5, variant)
    print(variant, f"{state['GM']:.6f}")
    for region in sorted(state['regions'], key=lambda r: r['x']):
        print(region['phase'], f"{region['x']:.9f}", f"{region['f']:.6f}")
```

Save to `/tmp/binary_tool_cell.py`, run
`PYTHONPATH=. poetry run python /tmp/binary_tool_cell.py`.
First row: `homogeneous 0.500000 -3763.172233 12000.000000`.
R1 prints two `ALPHA` rows, compositions 0.169144007 and 0.830855993, each amount 0.5.
The supplied tables are the paper route; reading a named output is the core task,
not independently implementing pycalphad internals.

## Scope and sources

The tool comparison covers G/H/S at three temperatures and seven compositions
for both I2 branches and R1 ALPHA, plus 40 equilibrium cases. All fixed contract tolerances
pass. This is same-model representation verification, not experimental validation.
R1 tool equilibrium near Tc is **not checked** by this exercise; the narrow
plain-solver near-critical restriction from Lesson 7 remains distinct. Existing
NumPy-shape deprecation warnings from pinned pycalphad may appear; they are not
hidden by an upgrade.
