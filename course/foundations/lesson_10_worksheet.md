## Meeting 23 — source and model card

**A1 — worked source roles.** From the reading's four records, assign each to project question, bulk assessment lead, restricted pure-element input, or atomistic boundary lead. For each, write one claim it supports and one it cannot establish. Which exact linked page reports $\Sigma5$/$\Sigma3$ rather than the proposed [111] Ni boundary?

**A2 — guided source card.** Make columns for source ID, physical role, exact artifact/version, rights, model terms/reference, geometry/domain, independent check and status. Fill what is known for Mey's paper and the NIST Fischer `ipr1` page. Leave unverified fields as GAP. Explain why a paper DOI, a downloadable EAM file and a CALPHAD TDB are three different things.

**A3 — planted mismatch.** A colleague says: “NIST hosts the Fischer Cu–Ni EAM potential, so it is our licensed FCC Ni–Cu CALPHAD TDB and its $\Sigma5$ segregation is validated [111] Ni data.” Mark each unjustified step. What exact evidence would be needed to use any of these items in the proposed case?

**A4 — independent exit.** Write a four-sentence decision: proposed observable and units; strongest supported Ni–Cu source claim; first blocking bulk input; first blocking boundary input. Choose `READY` (every required input is exact, eligible and checked), `CONDITIONAL` (runnable, with named open conditions) or `GAP` (a required input is missing) for the executable case and defend it.

## Meeting 24 — reservoir calculation contract

**B1 — worked synthetic convention.** At $x_B=0.2$, use supplied $g=-9000$ J/mol and $g'=3000$ J/mol. Compute $\mu_A$, $\mu_B$ and $(1-x_B)\mu_A+x_B\mu_B$. Which derivative is $g'$? Why are these numbers unsuitable as Ni–Cu reservoir results?

**B2 — guided prerequisite chain.** Draw arrows from exact eligible TDB and rights → semantic/phase/reference audit → fixed $T,p,z$ and stable bulk equilibrium → independent numerical checks → held-out material comparison → boundary input. Add the actual amount basis and units at the chemical-potential arrow. Circle each stage for which the current Ni–Cu packet has accepted evidence.

**B3 — diagnostic.** Someone evaluates the homogeneous FCC branch at a supplied $x$ and calls the derivative “the stable bulk reservoir” without checking the phase equilibrium. Explain the missing check. Someone else uses only the exchange slope $g'$ as $\mu_{\mathrm{Cu}}$. Give the correct relationship and identify the missing reference term.

**B4 — independent exit.** State the conditions under which two bulk phase regions have one common pair of component chemical potentials. Name both conserved amount balances. Write a short stop statement for Lesson 10B today, including the status of case selection and of the bulk model, and the next evidence needed. Do not supply real numbers.
