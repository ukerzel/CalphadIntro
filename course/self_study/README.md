# Guided self-study presentation

Original narration in lessons.json adapts the course content for individual
reading. It changes delivery, not models, exports or scientific definitions.
The classroom worksheets, notebooks and instructor notes remain authoritative
in-class resources; this route replaces pair prompts with predictions and
self-checks and omits classroom clock times. Detailed lessons remain optional.

The start module ends with a glossary of terms used in later steps; the last
module links the repository's Tasks 02–04. Learner text stays plain.

Four finite block types: paragraph, list, table, reveal. Paragraphs may carry
structured links and original-image fields. Reveals cannot nest. No HTML or
expression execution. The site copies only named content and approved outputs,
with its own build receipt; the science attribution stays in the source files.

Material pages adapt Tasks 01 and 05 only. Required exercises use supplied values;
TDB expression arithmetic and publisher-figure comparisons require fetched source
access and remain optional extensions. Original output copies are byte-identical.
No full TDB, publisher figure, private upload or other course subtree is copied.
