# Course notebooks

Runnable notebooks shared by the classroom primers, the Task 00–05 worked
examples, the lesson library and the self-study site.

**Suggested order on your own:** [setup_check](setup_check.ipynb) →
[f0](f0_jupyter_and_potentials.ipynb) → [f1](f1_unary_by_hand_and_code.ipynb) →
[f2](f2_unary_pycalphad.ipynb) → [f3](f3_binary_mixing_potentials.ipynb) →
[f4](f4_two_phases_and_diagrams.ipynb) → [f4b](f4b_lens_from_scratch.ipynb) →
[f7](f7_boundary_open_closed.ipynb) → [f8](f8_boundary_states.ipynb) →
[f5](f5_binary_pycalphad.ipynb) → optional [f5b](f5b_tdb_anatomy.ipynb) →
[task01](task01_cuni_equilibria.ipynb) → [task05](task05_ninb_sublattices.ipynb),
the order of the website's steps 00–06. Further tasks after step 06:
[f6](f6_fitting_synthetic.ipynb) → [task02](task02_cuni_activity_fit.ipynb) →
[task03](task03_ni_twin.ipynb) → [task04](task04_cuni_segregation.ipynb).
Each notebook's last cell suggests a next one (the classroom order). Try each "Your turn" cell before
running the collapsed "After your attempt" cells.

The **advanced steps 07–18** (optional) have their own notebooks, in this order:
[f4o](f4o_thermo_for_optimisers.ipynb) (thermodynamics for optimisers; for
readers coming from operations research) → optional [f4p](f4p_lp_primer.ipynb)
(linear programmes from scratch, for readers who have never met one) → [f4c](f4c_master_and_dual.ipynb)
(the menu, its line and its prices) → [f4d](f4d_column_generation.ipynb)
(column generation, ceiling and floor) → [f4e](f4e_global_pricing.ipynb)
(local search, keep pricing and branch-and-bound); optional:
[f4g](f4g_dual_view.ipynb) (the dual view: Lagrangian bound and cutting planes),
[task01b](task01b_cuni_gap_curve.ipynb) (the gap curve in the published Cu–Ni database),
[f4f](f4f_ternary.ipynb) (three components) and [f6b](f6b_fit_an_elephant.ipynb)
(fit an elephant: is the model good enough?).

The Colab links open this release.
Colab runs Python 3.13
with the locked package versions (the local course environment is Python 3.12).

**Primer demonstrations (instructors).** The primers stay paper-first; use a
local kernel started before the session, never a live install. W5 (15 min):
f1 section 2, the Lesson 1 cell unchanged, then change the temperature to 950 K.
W7 (15 min): f2 sections 1–3 (database text, `calculate`, `equilibrium`, then
the SOLID-only result at 1100 K). Day 2 demonstrations are optional and only
reproduce the checked synthetic results: f3 (D1–D3), f7 (D4–D6, D9), f8 (D7).
The worksheets' printed outputs remain the fallback, and
[instructor_exports/](instructor_exports/) holds executed HTML copies of f0–f8 and f4b
(all results shown, so for instructors; regenerate with
`.venv/bin/python notebooks/export_html.py` after changing a notebook). Offline,
their formulas show as TeX source; text, tables and plots are embedded.

**Run locally.** From the course folder: `poetry install --with dev`, then
`poetry run jupyter lab` and open a notebook in `notebooks/`. The first cell
finds the course folder; run cells from top to bottom.

**Run in Colab.** Open the `.ipynb` from GitHub in Colab. The first cell
downloads the tested course release and the locked package versions (a few
minutes the first time). It then restarts the session, which Colab reports as a
crash; that is expected: run the first cell again, then the rest of the notebook.

**Published databases** are fetched by your own session into a folder outside
the course checkout and checked by size and SHA-256; if a download is refused,
the notebook says how to get the file in a browser (and, in Colab, to upload it).
Sources and citations: [course/sources/README.md](../course/sources/README.md).

**For authors.** Edit the percent-format `.py`; the paired `.ipynb` is generated
with `poetry run jupytext --sync notebooks/NAME.py` and committed without
outputs. Every notebook starts with `SETUP_CELL` from
[helpers.py](helpers.py). After changing `poetry.lock`, run
`.venv/bin/python notebooks/export_requirements.py`. Checks:
`.venv/bin/python -m pytest tests/test_notebooks.py`.
